## 1. 简介

### 1.1 SfUi 是什么

SfUi 是一个把 Salesforce CLI（`sf`）日常操作搬进 Windows / macOS 桌面 GUI 的工具。它使用已授权组织的访问令牌直接调用 REST / Tooling API，因此 SOQL 查询、备份等操作速度很快。

```mermaid
flowchart LR
    A[SfUi 应用] -->|执行 sf 命令| B[Salesforce CLI]
    A -->|REST / Tooling API<br/>访问令牌| C[(Salesforce 组织)]
    B --> C
    A --> D[本地数据<br/>历史、设置、备份]
```

主要功能:

- **查询与开发**: SOQL（构建器 / 直接输入）、匿名 Apex、调试日志查看与分析
- **组织管理**: 组织列表、连通性测试、登录/注销、调控器限制、迁移盘点
- **组织信息**: 20 多个分区（用户、简档、对象、流等）的汇总显示、搜索与文档导出
- **数据导入导出**: 按对象的导出 / 导入（CSV、映射）与访问权限检查
- **备份与恢复**: 按对象备份、按 Id / 关键字段恢复、备份间比较
- **组织比较**: 最多 8 个组织并排比较（含对象字段与记录级比较）
- **ETL（数据迁移）**: 在文件、数据库、REST API 与 Salesforce 之间迁移数据；步骤与映射、增量（delta）模式、执行前验证与回滚
- **源代码编辑器**: 浏览 / 编辑 Apex、触发器、Visualforce、LWC 与 Flow 元数据，并部署到组织；Flow 图表、自动补全与 AI 支持
- **AI 助手**: 生成并一键应用 SOQL / Apex 建议
- **效率提升**: 收藏（Ctrl+1..9）、历史重放、终端 / 资源管理器 / VS Code / 浏览器联动

所有数据都保存在本地（设置的数据文件夹），不会发送遥测。只有使用 AI 聊天时，输入内容才会发送到所配置的 AI 服务。

### 1.2 运行环境

| 项目 | 内容 |
|---|---|
| 操作系统 | Windows 10 1809 及以上 / Windows 11、macOS 11 及以上（Apple Silicon） |
| 必需 | 已安装 Salesforce CLI（`sf`），且至少有一个通过 `sf org login` 授权的组织 |
| 分发形式 | Microsoft Store（MSIX）/ 便携版 exe / macOS 应用 zip |
| 网络 | 操作组织时需要网络；浏览本手册与管理本地历史可离线进行 |

### 1.3 术语

- **组织（Org）**: 连接目标 Salesforce 环境，用别名或用户名指定。
- **target-org**: `sf` 命令的目标组织；与顶部栏的「组织」联动。
- **SF 文件夹**: `sf` 命令的工作目录（例如部署的项目）。
- **数据文件夹**: 历史、设置、备份的保存位置（可从设置界面打开）。

## 2. 安装与初始设置

### 2.1 安装（Windows）

1. **从 Microsoft Store**: 在商店中搜索「SfUi」并安装（自动更新）。
2. **从 MSIX 文件**: 从发布页面下载 `SfUi-<ver>-x64.msix` 与 `.cer`，然后
   1. 双击 `.cer` →「安装证书」→ 存储位置选「本地计算机」→ 放入「受信任的发布者/受信任人」（需要管理员权限）。
   2. 双击 `.msix` 完成安装。
3. **便携版**: 将 `SfUi.exe` 放到任意文件夹直接运行（无需安装）。

### 2.2 安装（macOS）

解压发布页面的 `SfUi-<ver>-osx-arm64.zip`，将 `SfUi.app` 移动到「应用程序」。若首次启动出现 Gatekeeper 警告，请在 Finder 中右键 `SfUi.app` →「打开」，或执行:

```
xattr -dr com.apple.quarantine /Applications/SfUi.app
```

### 2.3 首次启动（欢迎界面）

首次启动会显示欢迎界面。

![欢迎界面](images/en/03-welcome.png)

- 切换界面语言（English / 日本語 / 简体中文 / 한국어）
- Salesforce CLI 检测结果。未找到时提供官方安装页面链接与 npm 安装命令（`npm install --global @salesforce/cli`）
- 主要功能介绍
- 「开始使用」进入主界面；「打开设置」跳到设置页
- 勾选「不再显示」后不再出现（可在设置中重新显示）

### 2.4 准备 Salesforce CLI（sf）

SfUi 通过调用 `sf` 命令获取组织信息并执行部署。

1. 安装 Salesforce CLI（官方安装程序或 npm）。
2. 在终端执行 `sf org login web`，用浏览器登录。
3. 启动 SfUi，顶部栏的组织列表会出现该组织。

若 `sf` 不在标准位置，可在设置页的「sf 路径」指定（留空则自动检测）。

### 2.5 注册组织（3 种方式）

在组织管理窗口的「注册组织…」面板中选择方式:

```mermaid
flowchart TD
    Q{选择哪种方式？} -->|在本机正常登录| W[浏览器]
    Q -->|从另一台机器迁移授权信息| S[SFDX 认证 URL]
    Q -->|已有访问令牌| T[访问令牌]
```

| 方式 | 用途 | 输入 |
|---|---|---|
| 浏览器 | 常规登录 | 实例 URL（可选；Sandbox 等需要） |
| SFDX 认证 URL | 从其他机器迁移授权信息 | `force://…` URL，或 `sf org display --verbose --json` 的输出 JSON |
| 访问令牌 | 用已有令牌连接 | 实例 URL（必填）+ 访问令牌 |

可指定别名（可选）与「设为默认组织」，然后点击「注册」。

### 2.6 数据保存位置

历史、设置、备份、日志都保存在本地数据文件夹。当前位置显示在设置页的「数据文件夹」，点击「打开数据文件夹」即可打开。也可以用 `--data-dir` 启动参数指定其他文件夹（便于多套配置切换）。

## 4. 查询、开发与执行

### 4.1 执行 SOQL

![执行 SOQL](images/en/02-main-results.png)

1. 在顶部栏选择组织。
2. 在 SOQL 选项卡输入查询（Ctrl+Space 可补全）。
3. 按 **Ctrl+Enter**（或运行按钮）执行。结果显示在网格中，状态栏显示行数与耗时。
4. 优先使用 REST，必要时回退到 CLI。

- **多标签页**: 点击标签行右端的「＋」可新增查询标签（「SOQL 2」等）。各标签独立保留编辑器内容、执行结果与运行状态，可并行执行并比较多个查询。用「×」关闭标签（最后一个标签无法关闭）。标签内容会自动保存，下次启动时恢复。
- **重命名标签 🖉**: 点击子标签的铅笔图标可修改标签名。留空则恢复默认编号（「SOQL 1」等）。自定义名称在重新排序后仍会保留，下次启动时也会恢复。
- **复制标签 ⧉**: 点击子标签的复制图标，可在当前标签右侧新建一个继承查询内容与名称的标签（名称为「…（副本）」）。适合在原有查询上小幅修改后执行。
- **多语句 SOQL**: 用 `;` 分隔多条 SOQL，会从上到下依次执行，**每条语句都有独立的结果面板**纵向排列（最多 20 条）。面板超出时显示滚动条。每个结果面板都有**筛选框**，只筛选该结果（显示当前行数 / 总行数）。只有一条语句时仍使用原来的单一表格。补全也以**光标所在的语句**为准，第二条语句会提示该语句 FROM 对象的字段（不再是前一条语句的对象）。
- **面板的复制与导出**: 在结果面板中选择单元格或行后按 **Ctrl+C** 即可复制（包含列标题行；未选择时复制当前显示的全部行）。**复制结果**、**导出报告**、**导出 CSV** 也支持多条语句：剪贴板和报告会包含每条语句带标题的表格，CSV 会写成 `<名称>-1.csv`、`-2.csv` …（有筛选时仅导出当前显示的行）。
- **注释**: 支持 `--` 行注释与 `/* … */` 块注释。执行前会被移除，也不会出现在面板标题中（可用作语句间的备注）。
- **缓存显示**: 重复执行相同查询时，先立即显示上次的结果，并在后台获取最新数据。缓存显示期间状态栏会出现「缓存 · 时间」徽标，获取完成后自动消失。
- **构建器**: 用 GUI 组合对象、字段、条件、排序与 LIMIT 后执行。
- **CSV 导出**: 将结果网格保存为 CSV（UTF-8 带 BOM，可直接用 Excel 打开）。
- **历史**: 每次查询都会记录，可从历史下拉中调用。
- 勾选「Tooling API」可经 Tooling API 执行（元数据类对象需要）。
- **固定显示 Id 列**：结果网格始终将 **Id** 列放在第一列；查询未选择 Id 时会自动补充（无法返回 Id 的聚合查询保持原样）。点击 Id 可在浏览器中打开记录页面（Lightning）。
- **直接编辑单元格并反映到组织**：除 Id、创建 / 更新日期等系统字段和关系字段外，可直接编辑结果网格中的单元格。已编辑但尚未反映的单元格显示为黄色，反映错误显示为红色。工具栏的「应用到组织 (n)」按钮仅将编辑过的字段批量更新到组织（REST 使用 composite，Tooling API 逐个更新）。

![SOQL 结果网格](images/en/04-soql-results.png)

### 4.2 运行匿名 Apex

![匿名 Apex](images/en/05-apex.png)

1. 在 Apex 选项卡输入代码（可插入模板）。
2. 按 **Ctrl+Enter** 执行，`System.debug` 输出会作为日志显示在右侧。
3. 执行结果（编译错误 / 输出 / 调试日志）会记录到历史。

- **多标签页**: 「＋」可新增标签；各标签独立保留代码与日志，适合并行运行多个脚本。用「×」关闭标签（最后一个标签无法关闭）。标签内容会自动保存，下次启动时恢复。
- 支持日志保存 / 复制，以及重新载入以前的代码。
- **仅显示 System.debug**: 打开工具栏上的勾选框后，日志区域只显示 System.debug(...) 的输出（USER_DEBUG 行）。

### 4.3 调试日志与解析

![调试日志](images/en/06-logs.png)

1. 在调试日志选项卡点击「获取」，列出组织的日志。
2. 选择某行，点击「获取」（查看内容）或「保存」（写入文件）。
3. 「打开 .log…」可载入本地日志文件。

对已获取或本地日志点击「解析」，会打开解析窗口。

![日志解析](images/en/07-log-analyzer.png)

- **概览**: 总耗时、事件数、SOQL 次数 / 行数、DML 次数 / 行数、Callout、异常数
- **树**: 嵌套执行结构（按方法的耗时与行数），展开慢节点定位原因
- **事件**: 全部事件列表（分类筛选、关键字搜索、选中查看详情）
- **限制**: 调控器限制使用情况（按使用率降序）
- **CSV 导出**: 将概览 / 限制 / 慢处理 / 事件导出为 CSV

最多显示 20,000 个事件（超出仅显示数量）。解析在本地完成，不消耗 API。

### 4.4 部署

![部署](images/en/10-deploy.png)

- 选择 SF 文件夹（项目）、操作（部署 / 验证等）与测试级别后执行。
- 结果记录到历史，可从历史下拉中重放。

### 4.5 命令

![命令](images/en/11-command.png)

- 直接输入任意 `sf` 命令并执行（Enter 或运行按钮）。
- 可查看标准输出 / 标准错误、加入收藏、从历史重放。
- 执行时会禁用 CLI 遥测（`SF_DISABLE_TELEMETRY`）。
- **多标签页**: 「＋」可新增标签；各标签独立保留输入命令与输出。用「×」关闭标签（最后一个标签无法关闭）。标签内容会自动保存，下次启动时恢复。

### 4.6 REST API 控制台

![REST API](images/en/09-rest.png)

- 选择方法（GET / POST / PATCH / DELETE 等）+ 路径 + 请求体，直接调用 REST API。
- 响应会格式化显示（JSON 美化）并记录到历史。

## 5. 历史记录

![历史记录](images/en/08-history.png)

历史选项卡自动记录 SOQL / Apex / 命令 / REST API / 部署 / 组织操作 / 数据导入导出。

- **筛选**: 类型筛选 + 全文搜索
- **重放**: 双击某行，将其载入对应选项卡重新执行
- **复制参数**: 复制所选行的 SOQL / Apex / 命令正文
- **删除**: 删除所选行（**Ctrl / Shift 点击多选后可批量删除**），或「全部删除」
- 历史上限可配置（默认每类型 2,000 条）。较大的执行结果会单独保存在 `results/`（默认超过 64KB 时）

## 6. 组织管理

从顶部栏「组织管理」打开，共 3 个选项卡。

### 6.1 组织选项卡

![组织管理](images/en/13-orgmanage.png)

网格显示默认标记（★）、别名、用户名、Org ID、类型、状态、连通结果、标签、备注、最后备份、实例 URL。

**工具栏操作**:

| 按钮 | 说明 | 多选时 |
|---|---|---|
| 重新加载组织 | 刷新列表 | - |
| 设为默认 | 更改 target-org | 显示**「此操作请只选择一个组织」** |
| 在浏览器中打开 | 打开组织 | **依次打开所有选中的组织** |
| 添加登录 | 浏览器登录（`sf org login web`） | - |
| 注销 | `sf org logout` | **批量注销所有选中的组织**（带数量的确认） |
| 连通性测试 | 只读 REST 检查 | **依次测试所有选中的组织**（进度、取消、OK/NG 汇总） |
| 测试全部组织 | 测试所有已注册组织 | - |

## 14. ETL（数据迁移）

通过顶部栏的「ETL 迁移」打开。它可在文件、数据库、REST API 与 Salesforce 之间迁移数据，重视 BCP（业务连续性）：执行前检查、失败时恢复与作业管理都在同一个窗口中完成。窗口由「作业编辑器 / 运行监视器 / 还原管理器 / 连接管理器」四个选项卡组成。

![ETL 作业编辑器](images/en/24-etl-job.png)

### 14.1 作业编辑器

- **步骤**: 从上到下依次执行。可在「画布视图」（默认）与表格式之间切换；节点上的 ← → × 用于排序与删除，右侧的「添加步骤」用于新增。所选步骤的设置显示在下方详情窗格中。
- **输入源**: CSV / TSV / Excel / JSON / XML / 数据库（SQL Server / PostgreSQL / ODBC）/ REST API / Salesforce（SOQL、Bulk API 2.0）。CSV 可勾选「将首行作为标题行」；REST 支持 URL、分页与认证（Bearer / Basic / 自定义标头）；数据库需指定提供程序、连接字符串与查询。
- **映射**: 以表格定义源列 → 目标字段，可设置类型（文本 / 数值 / 日期等）与表达式。表达式支持 56 个内置函数（字符串、数值、日期、逻辑、系统值、查找、Salesforce Id 转换）；函数提示常驻显示在映射表格下方。
- **输出**: Salesforce（插入 / 更新 / Upsert / 删除）、CSV 或数据库。选择 Salesforce 时需指定对象、操作、匹配键与错误率阈值。
- **增量（delta）模式**: 指定增量列与增量状态键后，仅迁移上次执行之后的变更（SOQL 输入会把条件下推到 WHERE 子句）。
- **多步骤联动**: 前一步骤创建的 Id 会记录到本地对照表（crosswalk），后续步骤可将其作为匹配键引用（例如父 → 子关联迁移）。
- **作业管理**: 「保存作业」「读取」「删除」「导出…」「导入…」。导出文件不包含凭据。

### 14.2 执行与监控

执行前会进行 Preflight（架构验证、实际件数、API 限额、现有键检查）并自动备份。应用到非 Sandbox 组织时会要求明确确认，删除操作默认禁用。「验证 (dry-run)」可在不写入组织的情况下检查。

![ETL 运行监视器](images/en/25-etl-monitor.png)

- **运行监视器**: 显示处理 / 成功 / 失败 / 跳过件数与日志。可查看失败行详情、导出失败行 CSV、仅重试失败行，并支持「停止」「继续」。
- **健壮性**: 暂时性错误会自动重试（指数退避）；当错误率超过阈值时自动停止。批级 checkpoint / resume 支持中断后继续。
- **验证**: 执行后自动比对件数、样本值与数值合计（可勾选「执行后验证」，也可手动「验证」）。报告保存为 verification.json。
- 执行摘要会以「ETL」类型记录到历史记录选项卡。

### 14.3 恢复（回滚）

所有已应用的变更都会记录在执行 journal（before / after 镜像）中，可按逆序（子 → 父）回滚。

- **自动回滚**: 应用失败时的选项（开 / 关）。未解决的行会被报告，并提供手动恢复入口。
- **还原管理器**: 选择执行（run）→「读取 journal」→ 确认变更 →「回滚此步骤/对象」或「回滚整个运行」。**成功之后任意时点的回滚**也在这里进行（journal 保留期内，默认 90 天）。
- **Salesforce 的恢复限制**（界面中也会提示）:

| 操作 | 恢复方式 | 限制 |
|---|---|---|
| 插入 | 删除已创建的 Id（移入回收站） | 不支持硬删除 |
| 更新 | 用旧值 PATCH | 公式 / 汇总字段不在范围内 |
| 删除 | SOAP undelete（保持原 Id） | 仅限回收站 15 天以内 |
| 全部 | - | 触发器 / 流的副作用（邮件、外部调用等）无法回滚 |

### 14.4 连接管理器

列出、创建与测试连接配置，并探索架构（数据库的表 / 列 / 类型，Salesforce 的对象 / 字段）。凭据经操作系统保护（Windows: DPAPI）加密保存，不会出现在日志或导出中。

### 14.5 ETL 数据保存位置

- `data\etl\connections.json` … 连接配置（机密字段加密）
- `data\etl\jobs\` … 作业定义与状态（增量 watermark 等）
- `data\etl\runs\<runId>\` … 每次运行的 run.json / src.sqlite（来源 DB）/ dst.sqlite（目标 DB）/ logs

## 15. 源代码编辑器

通过顶部栏的「源代码编辑器」打开。它可在类似 VS Code 的编辑器中浏览和编辑组织元数据源代码（Apex 类 / Apex 触发器 / Visualforce 页面 / Lightning Web 组件 / Flow），并轻松部署到组织。读取使用 Tooling REST；写入（部署）使用 `sf` CLI 的 deploy。

![源代码编辑器](images/en/26-source-editor.png)

### 15.1 浏览

- 左侧资源管理器按种类显示树（含件数）；「筛选成员」框可按名称部分匹配过滤。
- 选择成员会打开选项卡，带行号与语法高亮。LWC 会一起打开 js / html / css / meta 文件。
- 「重新加载」刷新列表与源代码。

### 15.2 编辑与部署

- 编辑内容会自动保存为本地草稿；关闭窗口或应用后可继续编辑。
- **未部署行的突出显示**: 与基线（最后与组织一致的内容）的差异会着色（修改 = 黄 / 新增 = 绿 / 删除 = 装订线 ▲）。
- **「部署到组织」（Ctrl+S）**: 通过 `sf` CLI 部署；没有修改时不执行任何操作。成功后高亮清除，并向本地历史添加快照。
- **「仅验证」**: 以干运行方式检查语法与可部署性。
- **部署错误**: 状态栏显示错误件数；点击错误列表中的行可跳转到相应行与列。
- **「新建」**: 从模板创建类 / 触发器 / Visualforce 页面 / LWC（校验 API 名称）。
- **「删除」**: 从组织删除成员（需确认；对应的本地历史也会清除）。
- **「保存…」**: 将当前文件导出到本地。可用 ×、Ctrl+W 或「全部关闭」关闭选项卡。

### 15.3 自动补全

- Apex: 输入时显示与「匿名 Apex」选项卡相同的候选项（System / 类 / sObject / 字段 / SOQL 片段），选择芯片即可插入到光标位置。
- LWC（JavaScript / HTML / CSS）与 Visualforce: 显示关键字与标记候选项。

### 15.4 Flow 图表

选择 Flow 成员时，会显示节点 / 连接图表而不是代码。

![Flow 图表](images/en/27-source-flow.png)

- 节点按类型着色（start / decision / screen / 记录操作 / 循环 / 操作等），连接线带标签（分支名等）。
- 点击节点可在下方查看详情。缩放滑块可缩放图表；「关闭图表」返回选项卡视图。

### 15.5 AI、搜索与本地历史

- **AI**: 通过工具栏的「AI」打开面板。可使用快速提示（说明 / 改进建议 / 修复错误）与「附加当前选项卡数据」（正在编辑的文件）；点击建议代码的「应用到编辑器」可插入到光标位置。
- **搜索**: 默认在组织范围内搜索（Apex / 触发器 / VF / LWC）；可用勾选框切换为“仅打开的文件”。最多 200 条，可在搜索中取消。点击结果会自动打开相应文件并跳转到该行。
- **历史**: 每次成功部署都会保存本地快照（最多 20 个版本）。选择版本会显示与当前的差分行数；「读取」恢复到编辑器，「重新部署」将其重新推送到组织（一键回滚）。「清除」删除历史。

### 15.6 源代码编辑器数据保存位置

- `data\source-editor\work\` … 用于部署的临时项目
- `data\source-editor\<orgKey>\<种类>\<成员>\` … baseline（最后与组织一致的内容）/ working（编辑中的内容）/ history.json（本地历史）

## 16. 疑难解答 / FAQ

| 症状 | 处理方法 |
|---|---|
| 组织列表为空 | 在终端执行 `sf org login web` 登录后，点击顶部栏「重新加载组织」 |

| 出现其他问题 | 查看数据文件夹中的 `logs\app-<日期>.log`，并附到 GitHub Issues |

## 18. 计划任务（定时执行作业）

用于**无人值守**地执行定期作业（报表、集成、清理等）。点击顶部栏的日历图标（**计划任务**）打开独立窗口（WPF / Avalonia 相同）。

### 18.1 窗口构成

- **日历选项卡** — 月视图（周日开始），今天、节假日、选中日期以颜色区分，日期格中显示预定时刻。用 `◀` `▶` 切换月份，**今天**返回当月。点击日期后，右侧显示**当天的作业**与**所选作业的详细信息**（类型、计划、下次、上次、目标组织）。
- **执行历史选项卡** — 显示执行时间、作业、类型、状态、耗时、目标组织、结果，下方显示输出摘要。**导出**按钮可输出 CSV / Markdown / HTML / Excel / PDF。历史默认保留 **90 天 / 最多 500 条**。

### 18.2 作业类型

| 类型 | 设置内容 |
| --- | --- |
| SOQL 执行 | SOQL、结果 CSV 保存位置（可选） |
| 匿名 Apex | Apex 代码 |
| 数据备份 | 对象（逗号分隔）、标签 / 说明（可选） |
| 数据导入 | 对象 API 名称、CSV 文件、操作（插入 / 更新 / 更新插入 / 删除）、外部 Id 字段、Bulk API |
| 数据导出 | SOQL、输出文件、格式（csv / json）、Bulk API |
| 执行报表 | 已保存的本地报表、输出格式（CSV / Excel / PDF / HTML / Markdown / JSON / TSV）、输出文件 |

> **输出文件**：相对路径会保存到 **`data/exports/`**（与应用的启动方式无关），绝对路径则按指定位置保存。可以用 **浏览...** 按钮选择位置，输入框下方会始终显示解析后的绝对路径。
| Salesforce CLI 命令 | `sf` 之后的参数（例: `org list --json`） |
| REST API 调用 | 方法（GET / POST / PATCH / DELETE）、路径、正文（JSON） |
| 操作系统命令行 | 命令行、工作文件夹 |

- SOQL / Apex / 备份 / 导入 / 导出 / 执行报表 / REST 需要目标组织（CLI 命令与操作系统命令行不需要）。
- **操作系统命令行是用户自行设置的高级功能。** Windows 使用 `cmd.exe /d /c`，macOS 使用 `sh -c` 执行。**请只注册可信的命令**（界面会显示警告）。

### 18.3 计划

- 可选择 **一次 / 每天 / 每周 / 每月 / 间隔（每 N 分钟）**。
- 重复计划可设置**跳过周末**与**跳过日本节假日**（含补休与国民假日）。
- 每月指定 31 日时，没有 31 日的月份在**月末**执行。
- 超过**超时**（分钟）的执行会被取消。**错过宽限**（秒）允许略微延迟开始。

### 18.4 通知

- 可设置**提前几分几秒**通知（默认 1 分钟），并分别开关**开始时**与**结束时**的通知。通知可按作业单独开关。
- 通知以**淡入 / 淡出弹窗**显示在右下角（最多 3 个）。失败与已错过的通知显示为红色。

### 18.5 已错过与手动执行

- 若预定时间 SfUi 未运行（或 PC 处于睡眠），该次执行记录为**已错过**，**不会自动重新执行**。
- 选中作业后按 **立即执行** 可手动运行（也可在执行历史中确认）。
- **跳过下次** 会跳过下一次预定，并记录为“已跳过”。

### 18.6 阻止睡眠

- 执行中或下次执行在 10 分钟以内时，SfUi 会**阻止空闲睡眠**（Windows: `SetThreadExecutionState` / macOS: `caffeinate`），状态栏显示“正在阻止睡眠”。
- 无法阻止屏幕关闭、手动睡眠或关机。此时该次执行将记录为“已错过”。

### 18.7 数据保存位置

| 内容 | 位置 |
| --- | --- |
| 作业定义 | `data\scheduler\jobs.json` |
| 执行历史 | `data\scheduler\runs\<yyyy-MM>\<runId>.json` |
| 单实例锁 | `data\scheduler\scheduler.lock` |

- 同一台 PC 上启动两个 SfUi 时，只有**先启动的实例**运行计划任务（另一个窗口会显示提示）。

## 19. 报表（本地 Salesforce 报表）

在自己的数据上创建 Salesforce 风格的报表，并通过实时更新保持最新。从顶部栏的柱状图图标（**报表**）打开窗口。

### 19.1 创建报表

1. **新建报表** → 选择**对象**。
2. 在**列**中添加字段（可修改标签以及数字 / 货币 / 百分比 / 日期 / 布尔值的格式）。
3. 添加**条件**（运算符和值；支持 `包含`、`其中之一`、`为空` 以及 `LAST_N_DAYS:30` 等日期字面量），并选择 AND / OR。
4. 根据需要设置**分组**（最多 3 个字段，支持日 / 周 / 月 / 季度 / 年粒度）、**汇总**（合计 / 平均 / 最小 / 最大 / 计数 / 去重计数）和**排序**。
5. 设置**行数上限**和**实时更新间隔**（秒，0 = 关闭），然后点击**保存**。

### 19.2 运行与实时更新

- 保存时以及点击**立即运行**时会执行报表。结果显示行网格、分组小计和合计；如果因行数上限被截断，会显示警告。
- **实时更新**会每隔几秒（默认 10 秒，最小 2 秒）重新执行。窗口不可见时暂停，连续失败 3 次后自动停止。状态栏显示上次运行、下次更新以及新增 / 更改 / 删除的行数。

### 19.3 导出

- 通过**导出**可将 **CSV / TSV / Markdown / HTML / Excel / PDF / JSON / JSONL / XML / YAML / PNG・JPEG 图片** 写入 `data/exports/`（相对路径会解析到此目录）。可以一次导出多种格式。

### 19.4 保存位置与票据

- 定义保存在 `data/reports/reports.json`，票据版面保存在 `data/reports/layouts.json`。

### 19.5 票据输出（SVF 风格）

- 工具栏上的**报表输出…**可针对当前结果选择或新建**版面**，并编辑**纸张**（A4 / A3 / Letter）、**方向**（纵向 / 横向）、**边距**、**页眉**、**明细行高**、**汇总**和**页脚**。
- 页眉 / 汇总 / 页脚支持合并域（`{Title}` `{Org}` `{Date}` `{Page}` `{Pages}` `{Rows}`），明细按每行一条记录重复，分页由纸张大小和明细行高自动计算。**保存版面**可复用该定义。
- 点击**输出**可用 **HTML** / **PDF**（通过已安装的 Chromium 内核浏览器打印）写入 **`data/exports/`**。

### 19.6 图表与仪表板

- 在报表编辑器的**图表**中可以设置**柱形图 / 条形图 / 折线图 / 饼图 / 环形图**、**类别（轴）**、**值**、**前 N 项**（0 = 全部）、标题以及是否显示图例。柱形和饼图按值从大到小排序，折线图保留行的顺序，饼图和环形图使用第一个值系列。
- 点击**立即运行**后，图表会显示在结果网格上方（相同类别会合计）。图表设置随报表一起保存在 `data/reports/reports.json`。
- 报表工具栏的**仪表板**会打开一个窗口，把设置了图表的报表以卡片形式排列。打开时自动刷新，并可手动**刷新**、按 N 秒（最小 10 秒）**自动刷新**以及切换组织。
